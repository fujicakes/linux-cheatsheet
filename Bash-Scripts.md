# Bash Scripting
Guide to some simple scripting

## Creating the file
`nano yourscript.sh`

## Shebang
The shebang is required at the beginning of the script
`#!/usr/bin/bash`

## Writing the script

`#!/usr/bin/bash`                              //this is the shebang

`echo "this is the first line of the script"` //first command in the script

`delay 1000`                                 //second command (waits one sec)

`echo "this is the third line of the script` //third command

## Make the script executable
`chmod +x yourscript.sh`
